# Sparkjam fonts

Latin subsets from Fontsource (https://fontsource.org), all under the SIL Open Font License 1.1:

- Press Start 2P (CodeMan38): labels and the logo
- VT323 (Peter Hull): Lumi's speech
- Space Grotesk (Florian Karsten): body text

They are declared in `fonts.css`, which each page links to.
